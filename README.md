I2C LCD 位址掃描與基本顯示功能
📌 專案簡介

本專案實作 I2C LCD 位址掃描工具，並結合 LCD 基本顯示功能測試，用來快速確認 LCD 模組的 I2C 位址與通訊是否正常。
此專案可作為嵌入式系統開發中，硬體 bring-up 與除錯流程的基礎模組，適合後續整合至感測、控制或工業系統中。

🎯 專案目的

掃描 I2C Bus 上所有可用裝置

確認 LCD 模組實際使用的 I2C 位址

驗證 LCD 顯示功能是否正常

建立可重複使用的 I2C 除錯流程

🧩 系統架構

微控制器（MCU）：Arduino / ESP32 / STM32（I2C Master）

顯示模組：I2C LCD（16x2 / 20x4，PCF8574）

通訊介面：I2C（100kHz / 400kHz）

MCU（I2C Master）
 ├─ SDA
 ├─ SCL
 └─ I2C LCD 顯示模組

⚙️ 功能說明
1️⃣ I2C 位址掃描

掃描 I2C 合法位址範圍（0x03 ~ 0x77）

透過序列埠（Serial Monitor）顯示掃描結果

用於解決常見問題：

LCD 無法顯示

位址設定錯誤

I2C 線路接錯或模組異常

2️⃣ LCD 基本功能測試

初始化 LCD 顯示模組

顯示固定文字與測試訊息

控制游標位置（列 / 行）

清除畫面與重新顯示

用於快速確認：

LCD 是否正常供電

I2C 通訊是否穩定

顯示控制指令是否正確

🛠️ 開發環境

開發平台：Arduino IDE

程式語言：C / C++

使用函式庫：

Wire.h

LiquidCrystal_I2C（或相容函式庫）

🔍 實作流程

初始化 I2C Bus

掃描所有可能的 I2C 位址

顯示偵測到的裝置位址

將掃描到的位址套用至 LCD 初始化

執行 LCD 基本顯示測試

🧠 問題與解決方式
問題	解決方式
LCD 無顯示	先執行 I2C 位址掃描確認位址

掃描不到裝置	檢查 SDA / SCL 接線與上拉電阻
顯示亂碼	確認 LCD 尺寸設定（16x2 / 20x4）
通訊不穩定	調整 I2C Clock Speed
